## 📊 Color Usage Guide

### Primary Color Usage
- Navigation bars
- Buttons (primary actions)
- Links
- Headers
- Focus states

### Secondary Color Usage
- Secondary buttons
- Icons
- Accents
- Highlights

### Background Colors
- **Main Background**: Page/container backgrounds
- **Secondary**: Content sections, cards
- **Tertiary**: Nested elements, slight contrast

### Text Colors
- **Text**: Body text, main content
- **Text Secondary**: Descriptions, placeholders
- **Text Tertiary**: Hints, disabled text

### Semantic Colors
- **Success**: Successful actions, confirmations
- **Warning**: Warnings, cautions
- **Danger**: Errors, deletions, critical actions
- **Info**: Information messages, notes

### Component Colors
- **Card Background**: Card surfaces
- **Card Border**: Card edges
- **Input Background**: Form inputs
- **Input Border**: Input edges
- **Button Hover**: Hover state

## 🎨 Color Accessibility

### Contrast Ratios (WCAG AA Compliance)
All themes are designed with WCAG AA compliance in mind:

- **Text on Background**: 4.5:1 (minimum for normal text)
- **Large Text**: 3:1 (minimum for 18pt+)
- **UI Components**: 3:1 (minimum for borders/outlines)

### Dark Mode Considerations
- Light text on dark backgrounds
- Reduced contrast to prevent eye strain
- Warm backgrounds (dark blues/grays) instead of pure black
- Secondary colors adjusted for visibility

### Light Mode Considerations
- Dark text on light backgrounds
- High contrast for readability
- Cool backgrounds (whites/light grays)
- Vibrant primary colors for interaction

## 🔄 CSS Variable Structure

### Naming Convention
```
--color-[type]-[variant]?
```

Examples:
- `--color-primary` → Main primary color
- `--color-primary-light` → Lighter variant
- `--color-primary-lighter` → Even lighter
- `--color-text-secondary` → Secondary text color
- `--color-card-bg` → Card background

### Fallback Values
All CSS variables include fallbacks:
```css
color: var(--color-text, #333);
background: var(--color-background, #fff);
border: 1px solid var(--color-border, #ddd);
```
