## 🎯 Feature Quick Start

### 1️⃣ Clear Activity History (Admin Only)
```
👉 Activity page → 🗑️ Clear All History → Confirm
```
**Does:** Deletes all activity logs from database
**When:** Clean up historical data

### 2️⃣ Refresh Asset Counts (Admin Only)
```
👉 Users page → 🔄 Refresh button → Wait 1s
```
**Does:** Updates asset count for all users
**When:** Need latest numbers

### 3️⃣ Reset Password via SMS
```
👉 Login page → Forgot Password → Enter phone → ✅ Done
```
**Does:** Sends 6-digit code to phone
**When:** Forgot your password

### 4️⃣ View Asset Lifespan
```
👉 Dashboard → See progress bar on each asset
```
**Does:** Shows remaining useful life
**When:** Track depreciation

### 5️⃣ Send Messages
```
👉 Messages in nav → Select user → Type & Send
```
**Does:** Send direct messages to colleagues
**When:** Need to communicate
